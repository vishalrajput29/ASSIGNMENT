### Project 1: Task Extraction from Unstructured Text
📌 Title: Smart Task Extractor: Identifying and Categorizing Tasks from Text
📝 Description:
This project focuses on extracting and categorizing tasks from unstructured text using a heuristic-based NLP approach. The system analyzes textual data, identifies action items, extracts responsible entities, and determines deadlines (if available). The project avoids pre-trained models, instead leveraging custom algorithms and NLP techniques to detect tasks efficiently.  


### Project 2: Sentiment Analysis of Customer Reviews
📌 Title: Sentiment Classifier: AI-Powered Customer Review Analysis
📝 Description:
This project builds a sentiment analysis model that classifies customer reviews as positive or negative using machine learning. It preprocesses text, extracts features using TF-IDF, and trains classifiers like Logistic Regression, Naive Bayes, and SVM. The model is deployed as a Streamlit app, where users can input a review and receive instant sentiment feedback.

## Installation

Install my-project with npm

```cmd
  conda create -p ./env python==3.10 -y
  pip install -r requirements.txt
  cd SENTIMENT_ANALYSIS
  streamlit run app.py
  cd ..
  cd TASK_EXTRACTION
  streamlit run app.py
```
